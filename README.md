# 🎮 DOĞU GAMES

> **CLASSIC GAMES. SIMPLE RULES. HIGH SCORES.**

Doğu Games is a retro-style browser arcade platform featuring a collection of classic mini-games, online score tracking, and a global leaderboard.

The project combines a nostalgic arcade aesthetic with modern web technologies to create a simple, fast, and entertaining gaming experience.

## 👾 BREAKOUT

Breakout is an enhanced arcade-style game featuring multiple waves, power-ups, combos and a final boss battle.

Players can:

- 🧱 Destroy blocks to progress through waves
- ⚪ Control the ball with the keyboard
- 🔥 Increase the ball speed gradually
- 💥 Build combos for higher scores
- ⭐ Collect power-ups
- ❤️ Manage multiple lives
- 👾 Fight a final boss after clearing the boss-stage blocks
- 🎯 Reduce the boss's health by hitting it with the ball
- 🏆 Reach the WIN screen by defeating the boss
- 💯 Save their final score to the leaderboard

The boss battle only becomes active after all blocks in the boss wave have been destroyed.

## 🏆 LEADERBOARD

Doğu Games includes an online leaderboard where players can compete for the highest scores.

Players can:

- 🎮 Play different arcade games
- 💯 Save their scores
- 🏆 Compete for the top positions
- 📊 Compare their scores with other players
- 🔐 Play with their own account

The leaderboard and score system are powered by **Supabase**.
