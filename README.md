# 🎮 DOĞU GAMES

> **CLASSIC GAMES. SIMPLE RULES. HIGH SCORES.**

Doğu Games is a retro-style browser arcade platform featuring a collection of classic mini-games, online score tracking, and a global leaderboard.

The project combines a nostalgic arcade aesthetic with modern web technologies to create a simple, fast, and entertaining gaming experience.

## 🕹️ GAMES

| 04 | ⌨️ **Typing Speed** | Test how fast you can type. |

---

## 🏆 LEADERBOARD

Doğu Games includes an online leaderboard where players can compete for the highest scores.

Players can:

- 🎮 Play different arcade games
- 💯 Save their scores
- 🏆 Compete for the top positions
- 📊 Compare their scores with other players
- 🔐 Play with their own account

The leaderboard and score system are powered by **Supabase**.
